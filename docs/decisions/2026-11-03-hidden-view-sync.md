# 隐藏目录合并刷新

本批减少采样后的界面重复工作，保持功能第472节。

定位到的问题：每次资源数值的采样时间更新，地图目录都会重新计算事件条件并重建整棵目录树，隐藏的藏品列表也会重新读取资料和筛选。只有工具条可见时，这些工作仍在界面线程反复执行。

现在隐藏目录立即接收完整的新地图和条件，暂不重建界面；打开时按最新数据刷新。隐藏藏品列表同样在显示前读取最新持有记录并复核来源。可见目录和仍打开的关联资料窗继续即时刷新。用户显式调用目录更新的原行为保留。本局合并、保存、采样频率、旧页补记和OCR均未改动。

采用现有Qt的显示事件接口，不新增框架或定时器。[Qt官方接口说明](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QWidget.html#PySide6.QtWidgets.QWidget.showEvent)。这不是仅合并绘制：昂贵的目录数据重建也延后到需要显示时执行。

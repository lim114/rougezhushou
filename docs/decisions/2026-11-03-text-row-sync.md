# 整页回退按文字行复用

本批减少重复文字推理，不增加功能节数，保持472。

已确认的原因：页面特征清单只覆盖干员详情、模组、队伍和藏品增益弹窗。探索与节点详情没有专用规则，因此实际地图画面回退整页读取，并非仅分辨率匹配失败。

处理方式：继续使用已安装的RapidOCR 1.4.4，逐帧检测整张当前画面的文字位置；将缓存单位从整批文字改为模型实际输入的单行。某行变化只推理该行，同批其它行仍可复用。宽度填充、解码比例及模型配置参与缓存身份，输入必须完全一致；新增、消失和移动的文字由当前检测决定。缓存限制24MiB、256行，不增加依赖。既有专用页面分批方式和局部变化读取保留。

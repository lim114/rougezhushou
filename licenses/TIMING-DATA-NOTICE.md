# 动画事件数据来源

`rouge/data/timing-profiles.json` 保留从公开游戏动画事件数据提取的数值及来源，不包含参考项目实现代码。数据来自 xulai1001/arkdps_data_collection，固定 commit `31269be4ca10124ca3f994ab33382dfc3d502991` 的 `customdata/dps_anim.json`。提取回执与原始 SHA-256 见该 JSON 和 `TIMING_MODEL.md`。

源仓库未确认提供适用于此数据的独立许可；不将既有聊天桥接 GPL/Apache 许可套用到本数据，不主张获得上游游戏资源的再分发授权。当前只保存用于本地机制测试的事件数值，未下载或分发角色动画、骨骼、纹理文件。对外发布前仍需核对数据使用与再分发条件。

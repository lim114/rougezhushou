# 维护：培养比较统一已装备模组的阶段校验入口

有非空模组身份时，阶段类型和范围由属性入口校验一次；比较入口只保留身份文字格式和无模组/零阶段的组合约束。无模组的布尔、浮点、空阶段仍在比较入口拒绝。原空字符串身份的既有接受行为保留，不在本批另改身份政策。没有新增辅助函数、catch或raise。

10项定向通过，基线2测试的7个子例证明重复入口提前拦截。正常培养285份报告及文字、4个整体错误与上一版一致。416个JSON输入组合的接受/拒绝与结果数据一致，56例错误文字或多错误优先级改变已逐项记录。没有跑全量。

Python内部调用的一项明确差异：IntEnum等整数子类不再被比较层type(x) is int提前拒绝，而是沿用属性入口已有isinstance-int契约；布尔仍拒绝。JSON没有整数子类，普通界面输入不受这项差异影响。不把这些提示/内部类型差异写成完全等价。

D118/D119宽捕获、D121信赖重复校验原样未改，只更新D121到当前共享入口名称；113组待审不变。模组阶段重复路径已销项；补充技能方案仍会经skill_reference再次准备培养，需要结合既有D125边界继续追踪，不声明普通全部完成。继续外层属性/天赋准备和其它模块。

测试窗口正常重启并可见响应，截图和原始对照只留.local；本批无外观或游戏操作。此为现有固定调用链去重，无需引入外部组件；维护不增加功能节数。

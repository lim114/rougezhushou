# 维护：技能矩阵按干员复用培养属性

skill_matrix原先先核验一次当前培养，每个技能通过主入口又重新取得培养属性。现本次查询内每名干员只取得一次，复用已有_prepare_damage/_calculate_prepared。当前干员保留模组；派生到其他干员时使用原有清理后的条件和无模组培养。其它干员直到首个开放技能才计算培养，锁定行仍只列原因。

技能本身的藏品、动作、个人强化和应急来源条件仍分别准备，不共享跨干员效果。初始条件核验顺序、全部既有raise/try内容不变；无新增辅助函数、恢复或保护。缓存只在本次查询存活，不涉及私人状态。

# 维护：本局效果入口一次分类与计算边界整理

费用、技力、治疗、伤害效果由run_skill_reference统一核验来源并分类，四个计算函数直接接收对应分类结果；不再在结果计算处重复核验。费用另传未支持费用桶，未知费用仍未知。自然回技在已合格的技力桶中按类型取出，单次使用的supported_natural_sp已内联到supported_sp。没有增加函数。

## 调用关系

| 路径 | 修改前 | 最终代码 |
| --- | --- | --- |
| 本局费用/技力/治疗/伤害 | run分类 → 各计算函数再次分类 → 计算 | run一次分类 → 各计算函数直接计算 |
| 自然回技 | supported_sp调用来源判定；计算时再次来源判定 | supported_sp一次核验 → 合格桶按sp_recovery取出 |
| 直接模块测试 | 传未分类效果，依赖计算函数过滤 | 按计算函数契约传已分类/未支持桶，来源过滤另由完整run路径测试 |

开工曾考虑保留“独立入口+共用计算”包装；核对确认其它调用只在测试，最终移除了四个临时包装，没有为假想调用者保留兼容层。费用函数新增明确的unresolved参数，其余函数同位置参数改为selected；所有实际产品调用只有supplemental_run，测试的直接调用已调整。未涉及对外插件协议。

治疗、伤害两个模块三条规则逐函数审查完成。伤害模块的资料缓存读取、循环内导入、每行创建类型表也已收拢。技力普通路径完成，D124待审；本局入口D122待审；费用的细分类来源查询仍有重复待继续审查。D38—D124共87组未擅自处理。

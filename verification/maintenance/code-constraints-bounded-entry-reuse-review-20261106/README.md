D115：组合入口两容差各校验一次，传给内部比较；独立面板/时刻/成对入口仍各校验。D116：有界面板已校验并复制转换记录，直接传内部成对比较，不再重复_record检查与复制。全部观察字段、来源身份等后续检查保留。

# 维护：敌人对照候选索引与难度环境复用

候选资料一次建立按敌人ID/等级查询的索引，不再对每个选择重扫列表。索引保留同键多条资料，原来的唯一匹配检查继续拒绝歧义。每个难度环境只准备一次，再用于各敌人；计算入口会复制环境，返回结果彼此独立。没有新增函数或异常出口。

三候选的资料扫描3→1次；两敌人两难度的对照模块环境复制5→3次（含最初快照）。9项定向通过，27份完整对照报告/文字、243个敌人难度结果与旧代码一致；覆盖常规敌人、领袖、源阶方、空配置/None配置/区域条件。输入与报告之间未发生共享修改。

前置完整计算仍未销项：实验确认原难度True或16会被该步骤拒绝，跳过后被对照难度4覆盖而通过。保留现有行为，后续应抽取真正的原始输入验证，不能直接删除，也不能把普通重复工作塞进待审批清单。基准投影仍受D123约束；D127默认难度回退未改。

原测试窗口已更新、可见响应；日志/截图仅在.local。仅定向检查，没有全量或游戏实测；无新增依赖，现有Python索引和局部复用足够。维护不增功能节数。

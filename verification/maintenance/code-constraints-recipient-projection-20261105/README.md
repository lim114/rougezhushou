# 维护：强化元信息投影与队伍选择去重

- 强化状态格式化只确认一次本局/在场状态、一次待确认字段集合。projected_run_metadata的可选mask只接收调用方刚解析的集合；未提供时保留原解析入口。没有缓存旧局集合，没有新增异常兜底。
- recipient_state先筛选本次实际符合触发/时间规则的条目，再计算一次未领取集合，复用于全部候选和最终更新。无触发时不读取该集合；原原因顺序、已领取正证据、同帧完整弹窗和旧记录优先规则保留。
- 队伍刷新每个列表只读一次选中项，培养过滤复用invalid_fields，技能等级类型只检查一次；删除未用math导入。
- 未增加单次包装函数。沿用Context-free的普通集合运算和既有Qt回调，本次局部精简无需引入外部组件。

# 维护：对照与藏品面板统一准备召唤物培养

模组对照在正常化培养后准备一次精英/等级，基础与升级各列共享，传给属性、模组、费用、数量资料。藏品面板同样按干员准备一次；不随召唤物变化的分队效果筛选也移到循环外，各召唤物结果仍独立。

原独立入口继续支持未预读培养；可选已解析输入供实际产品调用使用，无新辅助函数、捕获或恢复策略。干员原等级与召唤物截断等级分别使用。新藏品调用点仅对缺省/None使用满级，不复制D134假值默认；原五处D134以及D128/D129/D130均未改。

75项定向通过（中间0.548秒，最终0.526秒），新增2项改前均失败。望四阶段对照下游精英/等级读取各11→0，上层仍准备一次，未声称整体耗时同比降低。新旧120份完整报告、60份对照及1584条件7920项资料/属性结果相同，覆盖双召唤物，输入不变。未执行全量检查。

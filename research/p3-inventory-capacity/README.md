# 独立声明零件箱容量与整理方案

固定433770的超载规则原句支持容量条件阻断（含追猎），不证明每件占用、当前总容量或所有界面丢弃权限。来源完整网页SHA核对先前封存记录，摘录与产品规则另封；未据默认10补当前容量。

每实例独立来源/slot_units和容量都须调用方明示。完整清单+全已知权重才闭合总占用；已知下界超过容量可证声明超载，但不补未知占用/最少释放。独立保留偏好下，降序前k项证明最少释放实例数量，有限组合枚举另报未执行尾部，不按价值优先。假设丢弃后/领取后分别比较；领取不能复用旧ID，不真实执行或写库存。

API inventory_capacity_plan(snapshot,proposals,protected_ids,max_candidates,max_search_visits)；UI InventoryCapacityPanel是完整独立JSON编辑/复核/旧结果失效/阅读保留流程。容量不阻断不等于其它资格成立，actual_game_action_allowed始终None。示例全部是字面量占用算术，不是游戏测量。

独立穷举256组4实例权重验证最少数量及全部最少集合。两次只读审查提出保护输入默认、访问上限、重复JSON键和表述/下界显示，已修；首次8检查和复核9检查日志保留。原Windows/game/chat未验证。

# 线人 · 文献写明的物品资料

这是独立的文献物品参考，不是原表typed奖励记录，也不是本局领取、持有、资格或生效记录。它只服务于“线人”的完整选项“我受雇于梅兰德”，提供沙盘α的固定图标、完整用途、物品说明和解锁原文供用户手动查阅。

## 已证内容与边界

PRTS固定版427904、440271的完整“线人”事件组，在这个完整选项中明确写出“获得收藏品沙盘α”，`data-iconid`明确为`rogue_6_relic_final_1`。同一完整原游戏表中该名字仅对应此一个物品；`type`是`RELIC`、`iconId`同名，完整用途与PRTS说明相符。BWiki349818的完整标题与结果文字，也与原`choice_ro6_bomb1_1`的完整纯文本相符。

原选项的`displayData.itemId`仍是null，原目录的`game_choice_ids`仍为空。PRTS比原选项正文多出了“收藏品”及用途说明，差异未被删除或改写为“原入口已经绑定”。本包不改变原17条typed奖励合同，不减少25/57原始入口缺口。

“数量未确认”没有被补成1；藏品组合触发参数中的另一个`count:1`也不借来当本选项数量。部署费用+2属于物品用途，不是该节点扣除2源石锭。原物品的解锁说明“完成游戏结局”只按原文呈现，不自动判定本账号已解锁，也不作为本事件的完整出现条件。

资料还写明“本事件在未进入时会在同一局探索中重复出现”；未反推出进入后必不再出现。选项没有列出额外条件，只表示文献此处没写，不证明隐藏资格不存在。

## 接口

`event_item_references(event_id)`仅对本事件返回一条精确选项的`documented_named_item`参考。`item_details(event_id, scene_key, choice_key, item_id)`再次核来源和四个完整标识，然后返回完整物品资料。它们不接受来源数据、求值器或外部payload覆盖。

`DocumentedChoiceItemPanel.set_reference(event_id, *, scope_key=None)`仅设置阅读范围；不自动选择物品或打开详情。用户手动选择并点击“查看物品说明”后才展示图标和完整物品信息。相同范围刷新保留选择、已开详情、页签、文字选区和滚动；换范围或来源失效清空三个阅读页、选择和图标，恢复后也不自动重选。

完整固定原资料共105个关卡、68个独立level。其中70个关卡含279条这四类敌人的SPAWN引用；去除共享level别名后为149条原动作、44个配置随机组。组内四类敌人和空候选全部保留，配置权重不求概率，也不把四个候选相加成四件收藏品。enemyDbRefs仅用于精确身份/级别参考，不能证明生成。

2026-10-12查阅的PRTS敌人机制文档在四类敌人的0、1、2级分别说明：击倒后战斗结算获得1件收藏品。每个级别和版本入口分别记录在documented-outcomes.json；这里只存一条简短事实，不声称存有整页字节或奖励的原生/服务器脚本。文档分项进入预览，但当前模式实际出现、实际击倒、完整收藏品池、特殊实例修正与实际领取始终未知，不进入完整奖励总量，不修改本局库存。未知数据库级别、useDb=false、缺失引用或不匹配身份不继承数量1。

原主题mimic名单有5个ID，第5是小八界；完整固定105关卡没有它的引用，名单和未知资格仍保留，不解释为它在服务器永远不会出现。没有把它删除或用相邻敌人的数量代替。

位置只用主队列明确的原基础routeIndex和startPosition映射为名义格；没有借用主路线定位条件分支。当前原资料没有这五类的分支SPAWN，分支留未知的边界另外以公共临时输入验证，不能称为实机分支验收。

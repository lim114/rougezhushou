# 面板与时刻界限的联合核对

此功能推进首批三人的实际成对校准：独立读数可能只有视频帧覆盖范围或明确的四舍五入界限，不能自动降为精确数字。输入每项 `[下界,上界]`、固定上下文/干员/技能/面板身份、独立来源、同一时钟单位与显式视频FPS。没有默认游戏误差、精度、概率或置信度。

数值机制不变，模型参考复用 `paired_calibration.compare_paired_panels`、`timing_calibration.timing_reference` 以及固定原件 `a550f5e048bb94e7cdefc6eb97a4091f0c4c7add`。新增计算是声明范围的标准区间算术：独立后减前为 `[后下界−前上界, 后上界−前下界]`；模型差是原预测参考，残差区间整体减去模型差。两端绝对残差分别保留，防止相同偏移在差值中抵消。

时间域是连续时间覆盖区间。视频整帧只表示覆盖端点坐标，不约束未知事件一定出现在整数采样帧；不计算离散帧候选集合。转换不补半帧、一帧或任何默认误差。

时间差不能只独立减端点。调用方必须明确选择：

- `ordering_protocol=declared_normal_chain`：声明沿用就绪≤开启≤首释放≤末释放≤结束≤解除阻回≤下次就绪的正常链录入协议，连续释放与重复开启严格递增，重复结束/下一开启有顺序约束。它只是本次录入协议，不是原生游戏顺序已被证明。
- `ordering_protocol=explicit_constraints`：自行填写 `ordering_constraints=[{before,after,strict}]`。可为空；投射命中在技能结束后、特殊中断或未证先后不因事件名字被强制套正常链。约束仅支持非严格/严格先后，不补未知的最小间隔。

声明事件用 `A.ready`、`A.start`、`A.release.0`、`A.first_release` 等精确标识；部署原点用 `deployment`。未知时刻填 `null`，不能在显式约束中引用未录入界限的时刻。正常链会跳过未知记录，不补零。最多20周期、256个联合已录入时刻，显式约束最多512条。

求解使用输入十进制的精确有理数及排序可达关系：祖先下界、后继上界联合收紧；严格关系保留开端点，不加epsilon。同一首末记录与释放列表边界取交集，并同时保留原始读数和联合可行范围。非严格闭环可声明相同时刻；严格闭环、无交集或联合界限冲突拒绝。不可行仅说明与调用方已声明协议冲突，不证明实际游戏行为不可能。

每个比较显示 `all_compatible`（所有可行值均在明确容差内）、`possible_overlap`（仅有部分可行值重叠）、`no_overlap`、`model_unknown` 或 `measurement_unknown`。区间宽度不表示置信度；严格开端点不会把无法取得的0误判为可能重叠。FPS按调用方声明换秒，与模型30Hz预览独立。输出另保留 `lower_exact/upper_exact` 有理数端点，避免可读浮点显示丢失严格端点的信息。

初动仍对应部署→首就绪；回转对应记录结束→下次就绪且充值需求须声明匹配现有模型；周期对应开启→下次就绪，额外开启等待单独列出。预存/部分充能与非连续/命中/召唤物记录不会升级到本体回转或释放间隔参考。首出手、实际结束、解除阻回与因果仍未知；名义持续与模型估计单独保留。

`examples.json` 只有三人的 `[v,v]` 字面量公式退化界限，复现既有公开精确公式示例，没有默认误差。`reproduce.py` 另独立枚举小整数域可行赋值，核对每对端点的最小/最大时差，验证联合求解不是简单端点差或隐藏模拟。

```bash
.venv/bin/python research/p2-bounded-calibration/reproduce.py
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest tests.test_bounded_calibration -v
```

Qt `BoundedCalibrationPanel` 在一个工作区中独立编辑面板/时刻界限，提供来源保留、显式条件导入、标识确认、参考读取、开端点与比较状态。自动刷新和模板选择不替换记录；修改界限会清除过期结果。真正的游戏面板、测量精度、原生时钟、当前热更新或聊天仍未认证。

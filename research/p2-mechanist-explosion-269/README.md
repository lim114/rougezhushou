## 已证计算顺序

1. AOEDamage使用MAGICAL、`atk_scale`、BUFF_SOURCE/BUFF_OWNER及技能来源，模板明确 `useDamageFromBB=false`、`isNoSourceDamage=false`。`range_radius`为实际键；GetFloatOrDefault第四参数为 `showWarning`，不是取最大值开关。明确数字读取失败采用节点默认半径0，成功0保留0。倍率明确数字读取失败采用ONE，未知不当失败，成功0不替换。
2. CalculateDamageBySource在首次伤害计算回调之前独立读取两次来源ATK，先构造技能倍率AttackInfo，再构造ONE基准AttackInfo。两次不能默认同值。两次目标事件都启用，只有第一分支启用来源事件；第二分支source=null，因此来源固定/比例穿透均为0。
3. 进入CalculateDamageNoEvent的AttackInfo可能被各自前置回调改变，须提供独立事件后快照或明确无变化声明。GetFinalAtk先做FP乘法，仅 `scaleRaw > 42950` 时加入atkAddition，再Max(0)。42950边界不进入加项，42951进入。
4. FP raw单位为2^32。乘法等于 `wrap_signed64((x*y)>>32)`，负乘积向下取整，加减法signed64回绕。实际14指令高低半字乘法与独立算术向量核对；不改用double、中途十进制四舍五入或饱和运算。
5. 法抗先 `Max(0, RES−fixed)`，再乘 `1−ratio`。ratio为直接FP属性，无额外除100或自行限幅。剩余百分数为 `Max(0, 100−effectiveRES)`；先乘最终ATK，再乘float32来源0.01f（raw42949672），最后与最终ATK乘0.05f（raw214748368）的下限比较。运算顺序不可交换。
6. 普通法术分支CalculateDamageNoEvent直接返回内部公式结果。外层CalculateDamage缓存结果后调用后置事件，再返回缓存值；后置事件改变信息不自动重算该返回值。
7. originAtk在第一后置事件及第二伤害计算之后，重新从第一AttackInfo读取GetFinalAtk。因此它与第一次无事件计算输入不是同一时点；仅独立晚期快照或明确晚期无变化能计算参考。

# 来源、重建与验收范围

本包固定五份完整公共文献修订436092、441718、436178、427937、428754，以及固定国服原数据的完整选定记录。原HTTP记录、全文、首索引及显式术语索引修正一并保留。source-preparation-final 中的成功退出仅证明资料准备，不证明产品或Windows窗口验收。

运行期只依赖 manifest 列出的12份公开资料和当前选定对象；不联网，不读取游戏或聊天，不改数值模型/地图/本局状态。“痛苦将息”的原配置只用于说明版本差异，不新增该关卡的普通版技能入口。历史源文件中的 pursuit 为内部名称，不是已证实的游戏分类。

重建须提供固定完整原数据库与两份完整关卡，默认沿 source 中记录的本机缓存位置读取。可用 `--enemy-database`、`--normal-level`、`--pursuit-level` 指定另一台电脑上的同SHA完整原件；最后一项对应“痛苦将息”。这些选项只更换读取位置，不改变逻辑来源、完整SHA/长度和对象核对。片段、错版本或错关卡均拒绝，不以本包精选对象冒充完整原件。

`--check` 在临时目录重建并比较当前生成物，不覆写当前输出。三个完整原件缺失时，依赖它们的构建检查必须明确记为未执行；其余公开运行期检查仍执行，不能因此缩减注册范围或将缺件计为通过。

本节未新增实际形态、触发时钟、命中、增益层数、伤害或通关预测。固定文献覆盖与本局实机核验分别记录，后者没有因文献或测试通过而完成。

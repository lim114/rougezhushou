原片172秒分类与资源同处顶部：本轮宽1200时实际同一行，窄窗由同一Flow自然换行，不以固定分辨率切模板。初版把导航独立放在资源左侧，640宽资源被挤成7行、212高；改为共同排列，640宽资源区66高、窗口实际560高，480宽资源区99高。资源行数不包括导航所在行，不能混称整栏行数；当前四宽/一套DPI不能代表全部屏幕。

# 补充技能参数依据

固定原表 character_table/skill_table 的提交、URL及SHA256见 rouge/data/supplemental-skills.json。所存候选天赋和七级技能是原字段摘录，按精英、等级和潜能筛选。自身普通百分比属性沿用现有模型的加算层；物理伤害沿用 max(攻击-防御,攻击×0.05)，法术沿用抗性上限95。

仅单次技能参数及声明次数算术，不推算获取、结束、首跳、回转或周期；精零已培养高技能等级的实际可用性仍未知。藏品、科技和本局修正未接入此工具，不作为完整战斗估算。原生时钟和热更新/实机面板仍待核验。

七名干员的原字段一致性回执见 verification/full-140/source-evidence.json。本目录extract.py接受含两个固定原JSON的目录，先校验SHA，再重建七干员/49级技能片段；输出必须为不存在的新文件，避免覆盖现有数据。

克洛丝只测算普通攻击未触发/触发天赋分支与单次边际期望。二连射未触发天赋分支按两次独立扣防御求和；此处“独立扣防御”指每击分别结算，不证明随机抽样独立。天赋与二连射组合层及抽样相关性未找到足够证据，保持未知。wiki-search.json保留针对性公开来源查询及克洛丝页面503，未把失败的网页查询记作机制证据。

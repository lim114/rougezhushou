# 木质地面固定图映射

虫虫游戏厅、枝头陷阱的普通/紧急四个原关卡现在可以在已下载的原图上显示名义出生格、原路线检查点和选择格，并随预览窗口缩放。它们共享原图与网格，绑定仍分别检查每个关卡原ID、文件名、原图摘要、关卡摘要及网格摘要。

拟合前直接读取并冻结原图地面边缝角点和独立地块中心。只有角点进入无稳健排除的单应拟合；中心只用于验收。虫虫游戏厅12个独立中心最大偏差2.780原像素；枝头陷阱18个独立中心最大偏差3.974原像素。既有4原像素门不变，旧10张图/20个关卡/78个检查中心不改动。新总计12张图/24个关卡，尚有81个关卡、59张独立原图未校准。

这是原图上明确记录的低地木路/地板中心的一致性检查，不是整张地图、游戏截图或实体真实位置误差保证。未测量的边缘、高台表面、入口框顶部与地面脚点、出生偏移、随机范围、碰撞、寻路及实际到达时钟仍未知。枝头陷阱最大偏差接近验收界限；像素观察本身是近似读数，不能据此声称亚像素精度。

无主地和预算否决的首次冻结观察分别得到4.651、6.388原像素最大偏差，不符合门槛；全部原角点、中心和失败结果保留，未调点或放宽门槛，原图继续可看但不增加坐标覆盖。

来源为已有固定公开游戏关卡JSON与公开提取原图：Kengxxiao/ArknightsGameData `a550f5e048bb94e7cdefc6eb97a4091f0c4c7add`，fexli/ArknightsResource `d0b5af0b004b044d322397ce5ae79632b6d9fcdd`。完整原件、精确URL、摘要、原图Blob身份及对应关系见 `source-receipt.json`。游戏素材仍属于鹰角；不主张获得游戏图的额外许可。没有游戏操作、聊天请求或实时战斗采集。

`scripts/extend_fixed_map_projections.py` 默认接口 `build(write=False)` 只读重建；命令执行显式写入候选所在工作副本的生产投影数据。它拒绝源字节变化、失败观察晋升和仅凭名称继承校准。

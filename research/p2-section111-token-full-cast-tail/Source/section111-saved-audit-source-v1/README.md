# 第111节 Root Saved 审计准备

本包只准备 Source。作者未执行项目、Qt、Wine、原生证据读取器、pickle/gzip 解码或测试，未读取实际原生记录。Root 阅读与核对哈希后独自执行。

CLI 必需参数：--root、--guard（当前候选完整 Source/CORE）、--original、--candidate、--original-exit、--candidate-exit、--out（全新 JSON 文件）。可选 --window 和 --window-exit 必须成对提供。API 收据要求 v2 三格式化器探针的真实返回码为0，每阶段18情景、72次调用、90份原生证据；初次仅启动失败的目录不得冒充原版完成目录。

每条原生记录独立校验压缩及解码长度/哈希、协议4、无全局对象、精确类型、字典顺序、浮点位模式以及完整图内部双向别名。每个 API 调用前后完整输入一致；每条原生格式化器完整输入与该数值结果一致，保存所有三份完整文本。跨独立捕获之间不宣称共享对象身份。

10个无变化情景要求完整数值结果及全部三份文本精确相同。8个延迟尾段情景只允许已逐项核对的单次总伤、触手完整命中数、有限周期伤害/平均以及 damage 报告段发生变化，其余完整结果恢复允许项后精确一致。新增完整命中取同技能同延迟且无短观察窗口的实际 emitted_times_seconds；短/零观察窗口不被用来伪装完整施放流。实际增量来自实际额外命中数×实际 per_hit，并区分技能内、周期内和周期外命中；主窗口、所有当前分项、SP完整字段/事件/报告及普通充能时序必须不变。damage 段的每个字段、顺序、数值和可选窗口行按已读取的当前报告 Source 单独核对，未任意跳过整个报告。改变情景的格式化文本为已保存的完整实际文本，不声称与旧文本相等。

可选窗口部分核对所有原生记录，完整 UI 步骤前后本局/账户/磁盘只读，全部数值调用前后调用者只读，三格式化器联合完整结果/状态只读；4份实际快照、2组技能/延迟配对、完整调用者、完整文本、持续/窗口/命中时序、SP报告、本体独立分项、真实关闭及直接RunState重载、2份PNG原始字节哈希和实际可见文本块/视口矩形。Root仍需独自观看2张图片，命中数以原生数值证明，不声称图片肉眼显示它们。

精确相等（类型/浮点位）用于不变项目和保存图；算术增量因既有浮点总量求和顺序使用 rel_tol=1e-12、abs_tol=1e-7，未修改游戏参数、预期值或机制。输出不能代替 Windows 实机、游戏、聊天或采样验证。

所有未来运行信息均为 NULL；该准备包没有 PASS。

# 第305节：回滚文明与收藏品提供物

这份资料提供“回滚文明”的完整固定社区目录阅读，以及固定本体272件收藏品能否作为交换提供物的原资料核对。它不读取、改写库存，不替用户选择，也不列出推测奖励池。

## 已核实范围

- 事件是 `community_group_025`“回滚文明”，节点类型为“失与得”。完整目录为11场景、19条选择/说明/导航记录。各记录保留 `presentation_role`，不能全部称作游戏按钮。
- 固定原表复用第300节公开本体 `research/p3-future-region-effects-300/game-topic-complete.json`，提交 `a550f5e048bb94e7cdefc6eb97a4091f0c4c7add`。272件完整 `RELIC` 对象中，`canSacrifice` 真251、假21；没有复制17MB文件。
- 角标模板433235明确 `notrade` 是“不可于【失与得】交换”；编目441474明确标志表示收藏品不能被“交换出去”。原表21个假旗标全部按各自原图标ID、中文名和实际角标逐卡对应。完整原页、21卡正文范围和哈希均保留。
- 这是提供物方向的核对。`canSacrifice=False` 不能排除奖励获得；`True` 不能证明本局实际可选、持有、数量、服务器完整资格或奖励档次。

- 两条“有点可疑／见好就收”的旧目录导航都指向场景5的“感谢你提供了宝贵的实验材料”结果；这来自完整事件页427904的实际 `data-dest=5`，保留为社区导航且原选择ID未匹配。完整调查记录349818却在两个独立分支均写出“它见你要离开”结果，与旧目录后续原文不一致。新增字段分别保留这两条独立补充文献及字节范围，不覆盖旧导航、不认定服务器实际转移。原表有4个完全同文场景，不能凭编号分配两条入口；两条都保留4候选及未恢复原入口标记。

编目441474包含后续内容拓展，只用于语义与21个禁止提供物的独立对照。它不使固定本体272件变为当前完整目录，不证明当前服务器与旧资料完全一致。

每次目标查询重新读取并校验完整的小型资料包、完整目标事件所在原目录，以及旧目录接口返回的完整事件；无可变资料缓存。任何成员缺失、变化或旧缓存污染，均返回 `source_unavailable` 并清空旧选择、物品和引用。查询不需要每次读取17MB原表；完整原表在构建时核验，所有272件完整原对象留在固定权威选取中。

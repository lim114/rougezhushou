`independent-reading-request.json`只包含原件身份、逻辑格编号和范围。作者先看原位图与带原像素轴的最近邻诊断，在`author-readings-frozen.json`冻结名义中心；另一读者只能看原图、原编号格图和不包含作者像素的诊断。不能把装饰框中心当作已证明的真实地面中心。遮挡使中心无法直接确认时必须保留null，不能从左右或上下已知点补齐。

(reporting.py 421–447). Independent unit and recharge streams are used only for
animation-reference notes. The emitted/current-window distinction already exists
in maintained producers (timing.py 337–356 and test_token_full_cast_tail_111.py),

not put all existing window/cast/phase/cycle *totals* and lengths together.

mechanics model or revalidating inputs.

## Important qualifications

* Deepcolor records one representative token stream for zero or many selected
  tentacles; its record count is not deployed-unit count or total hits.
* Shu/Mizuki can record several streams for one owner. Keep all indexes/order.
* Alias full-cast helpers can rebind times_seconds to emitted times while bounded
  impact_frames remain shorter. Each array is copied and labelled separately.
* Unknown/absent animation qualification does not become False or native proof.
* Unbound phases/acquisition/collision/secondary clocks remain unknown; a
  numerical record does not upgrade these flags or actual_total values.
* This first delivery is frame streams only. Ordinary continuous mode often has
  no stored streams; no frame data is recreated from hits or components.
* Raw scenario scalar display is defensive and does not coerce opaque objects
  or print unused opaque unit payloads. Parser and existing-error policy remain
  with the original calculation path.

# 令与麦哲伦六种独立实体：培养端点和直接模组属性对照

对应待办“其它召唤物模组、技能分型与独立实体”。完整功能组新增令清平/逍遥/基础弦惊、麦哲伦龙腾F/L/A六种技能绑定实体，分别计算原始培养端点加直接装备属性的条件参考，并比较模组0–3阶段的费用、生命、攻击、防御、法抗、官方攻速和基础间隔/阻挡参数。独立Qt窗口保留宿主培养快照，要求用户明确选择实体资料阶段及1级/满级端点，显示全部技能变体/模组阶段并可复制条件和结果。

固定原始提交 `a550f5e048bb94e7cdefc6eb97a4091f0c4c7add`：复用已匹配哈希的character_table，缺失的battle_equip_table和uniequip_table仅下载一次并逐文件核对已有固定SHA256。生产来源包保留6项完整原始技能绑定、6份完整实体记录、6项完整模组阶段及2份完整模组定义，原`overrideTokenKey`与`displayTokenDict`逐项相符。令`uniequip_002_ling`、麦哲伦`uniequip_003_mgllan`都要求精二60。宿主培养只核此门及技能门，不用于决定实体资料阶段、等级或属性。

模组直接加法依据复用069归档编译证据，基包 `26-08-16-14-00-43_415873`：`FetchUniEquipAttributeAddition`的isToken分支按实体key取`tokenAttributeBlackboard`，`FetchEquipAttributesAdd`把对应键的值写至装备加法数组，`TryGetFinalData`使用该数组。三方法、既有CFG文件和证据哈希记录在来源包，重放核对的是归档证据文件，不能称当前DLL/热更新字节已经重新核验。未采用天赋黑板猜隐藏能力或同时在场限制。

直接新增规则：令三种基础实体的各阶段费用分别-3/-3/-5，三级另生命+150/+100/+250、攻击+45/+35/+60；麦哲伦三种无人机费用-1/-3/-3，三级F生命+100/防御+50，L攻击+40/攻速+3，A攻击+50/攻速+3。原库存属性加值+3单独呈现，完整库存与并发限制未知。信赖、潜能及本体装备的白值没有进入实体结果。

PRTS令435035、麦哲伦435055独立明确相同直接加值。逍遥/弦惊/F/L/A实体页的公开精二90基础行与原表一致；5项独立公开参数成对计算与生产结果一致，见`paired-public-reference.json`。例如逍遥1217生命+100=1317、406攻击+35=441、9费用-3=6；F为2000生命+100=2100、200防御+50=250、3费用-1=2，攻击保持0。清平基数来自完整原表，模组加值有公开来源，但其实体页查询出现404/503/重定向循环，未冒充第6项独立双页成对例。

为保留来源边界，全组只支持显式原始实体阶段与两个端点；没有默认宿主等级选择、插值、宿主属性百分比继承或未读培养确认。该端点是反事实参考，不是当前实体培养已确认。技能强化、隐藏天赋/模组能力、当前完整实体面板、令S3合成大龙、库存/并发、实际存续时钟和完整伤害/治疗仍未知。已取得5实体页的“等级对应持有者等级”只作来源记录，不将清平缺证或阶段绑定缺口推广成整个组的新动态规则。

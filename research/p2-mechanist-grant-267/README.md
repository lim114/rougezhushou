## 数值链

`Q=4294967296`。正值无溢出乘法为 `(max_hp_raw*ratio_raw)>>32`，不是最近整数舍入。随后 `Assign(FP)→AsFloat→Assign(float)→GetFpOrDefault` 使即时乘积再次经过单精度。

`AsFloat` 先将int64直接转float32，再乘2^-32；不能经Python double先转换而引入双重舍入。实现使用整数尾数/余数，支持nearest-even、toward-zero、toward-positive和toward-negative四种**独立声明**模式。没有读取实际MXCSR；舍入模式未知则读回值及其依赖保持未知。单精度读回signed64越界与乘积越界保留未资格结果，不夹到最大值。

0.1f为bits `0x3dcccccd`、ratio_raw429496736。MAX_HP1000Q：即时乘积429496736000、读回429496729600；MAX_HP3001Q：即时乘积1288919704736、读回1288919711744。raw1×0.5得到0、raw3×0.5得到1。都是公开原件算式向量，不是游戏观测。

nearest-even最大安全正输入raw9223371761976868863；再大1可舍入成2^63，回读越界，不得cap。其它模式单独求值，不将nearest-even边界冒充全部环境通用边界。

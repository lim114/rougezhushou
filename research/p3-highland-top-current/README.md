# 独立高台名义表面参考 · 四确定格

本组只为显式逻辑高台格提供独立顶部名义中心显示。固定游戏/资源提交、原bitmap、完整原level和原mapData已核对。18格的作者与盲读者原字节均保留，未经调整、舍入或放宽原4像素一致性门：只接受未来见闻`(1,3)`、`(2,3)`、`(2,7)`、`(2,8)`四格。其余14格拒绝或未知，远北猎场没有高台运行参考。

普通/紧急未来见闻的两份真实图片文件分别验证SHA256/Git blob/尺寸/字节数，并确认原level和格网一致，故绑定`ro6_n_4_1`和`ro6_e_4_1`。这是1张独立位图中的4格，不重复累计别名。目视读数一致只支持名义顶面参考，不保证绝对误差、真实地面、入口脚点、干员落点、敌人出生位置或战斗坐标。

运行数据是独立`rouge/data/highland-top-references.json`，独立API使用`top_center`。原LOWLAND direct、常规平面、脚点和出生路径不被改写或复用。只有严格绑定原图、路径、尺寸、level、格网、tile_wall/HIGHLAND的显式整数格可得到点；其它格、非整数、逆向映射、插值及连路线均不生成。

完整资料窗口`HighlandTopDialog`提供真实普通/紧急ID、逐格高台选择器、原图符号与未知说明。未获得一致读数的格仍在选择器中，选中时清除点；同原件的两真实ID切换与同ID刷新保留未知格和用户选择。不生成原图反向点击或将符号用于路线/出生关联。

复建：`python scripts/build_highland_top_references.py`只读；明确`--write`才生成独立运行JSON及本目录比较回执。所有来源由仓库ROOT下本目录定位，不依赖work、私有缓存或当前对局。原始work候选与回执另留为历史证据，根模块的source_pack路径改为本公开目录，18格数据和全部取舍不变。

标准验收模块是`tests.test_highland_top_reference`（4项来源/API/全格未知与旧参考保护）及`tests.test_highland_top_view`（3项实际Qt对话框完整选择流、两真实ID/unknown刷新、无高台参考的木板图保持unknown、三种缩放和错误图片身份门）。候选隔离运行7项通过；原项目BattlePreviewPanel入口仍由根代理接入并核验。

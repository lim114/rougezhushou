## root集成入口

- `rouge.duel_reward_planning.is_duel_stage(stage_id)`限定两个直接来源关卡。
- `duel_rewards(stage_id=None, tier='left', context=None, success_declared=None)`返回全部固定ID分组、条件数量、来源与未证边界。
- `DuelRewardPanel.set_reference(stage_id=None, context=None)`、`set_context(context)`；`stageSelected(str)`仅打开固定战斗预览。目录狭路相逢功能节点可传None保留两份关卡，所选战斗可传精确ID。
- root负责在battle_view/node_catalog_view挂入口，本组未修改既有UI、App、全局文档或索引，也未commit/push。

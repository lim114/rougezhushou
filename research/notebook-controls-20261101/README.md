# 实现维护 · 备忘录操作换行、正文空间与上级内容自适应

按外部成熟方案优先，本轮核对Qt官方Flow Layout及TextEdit的操作分离方式。实际使用的是既有固定Qt for Python v6.11.2 BSD-3-Clause Flow代码，不是新引入项目，也不是仅把内部复用当外部采用。原作者、[许可](../../licenses/qt-flow-layout-BSD-3-Clause.txt)、原固定来源及当前源码摘要见[sources.json](sources.json)。完整TextEdit以QMainWindow与富文本文件为模型，不适合替换现有按场景保存的Markdown、冲突和导出语义；未复制完整示例或增加依赖。

真实八个既有控件移到Flow布局，在有上限的滚动选项区自动换行。默认收起，不替换编辑器或存储；正文至少保留四行当前字体空间。同一归属不重复占编辑区，不同归属草稿的提示移到区外，保存失败在收起更多操作后仍可见。上级内容按实际换行高度占空间，长内容上限200并滚动；空提示不再硬占150。公开样本的四宽480/640/900/1200实际客户区均480/640/900/1200×500，正文视口76、行距15；不是固定模板或全DPI验收。
